GERİ DÖNMEYENLER — Los que nunca regresaron
=============================================

Contenido del paquete:
- index.html : Plataforma web completa, lector digital bilingüe (ES/TR) y panel editorial.

Instrucciones de publicación:
1. Descomprime este archivo ZIP.
2. Sube el archivo `index.html` directamente a tu servicio de alojamiento web (Netlify, Vercel, GitHub Pages, Hostinger, cPanel, etc.).
3. Para abrir el Panel del Autor dentro de la web: haz clic en "Acceso Autor" en el pie de página e introduce la clave `1922-1959`.
